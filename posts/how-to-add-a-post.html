如何给这个博客添加一篇新文章

2026-10-09 指南

这个博客是纯静态的，添加文章只需要三步。

1. 新建文章文件

在 posts/ 目录下复制任意一篇文章，重命名为你的文件名，例如 posts/my-new-post.html。

2. 修改内容

把 <title>、<h1>、日期和正文替换成你自己的内容即可。常用的排版元素：

<h2>小标题</h2>
<p>一段普通文字，可以包含 <a href="#">链接</a> 和 <strong>加粗</strong>。</p>
<ul>
  <li>列表项</li>
</ul>
<blockquote>引用</blockquote>
<pre><code>代码块</code></pre>

3. 在首页加上卡片

打开 index.html，复制一段 <article class="post-card">，把标题、摘要、日期和链接改成新文章的即可。

发布

保存后提交并推送：

git add .
git commit -m "post: 添加新文章"
git push

稍等片刻，GitHub Pages 就会自动更新。
